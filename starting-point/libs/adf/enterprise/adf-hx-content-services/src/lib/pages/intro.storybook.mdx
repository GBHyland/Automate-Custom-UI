# Intro

The `@alfresco/adf-hx-content-services` simplifies the development of custom web applications
that interact with the Hyland Experience Repository (HxPR).
It provides Angular services and both presentational and smart components
to meet requirements with different levels of complexity and granularity.

This library is built on top of the Alfresco ADF core and leverages the Hyland HXCS JS SDK to communicate with the backend.
