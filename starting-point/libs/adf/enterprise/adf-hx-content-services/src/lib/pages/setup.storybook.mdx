# Setup

## Prerequisites

Make sure to have the following dependencies installed:

```ts
"@angular/common": "^16.2.0",
"@angular/core": "^16.2.0",
"@angular/animations": "^16.2.0",
"rxjs": "^7.8.0",
"@alfresco/adf-core": "latest",
"@hylandsoftware/hxcs-js-client": "latest"
```

## Installation

Install the lib:

```
npm i @alfresco/adf-hx-content-services@latest
```

Import the main lib module in your `AppModule`

```ts
import { NgModule } from '@angular/core';
import { CommonModule } from '@angular/common';
import { CoreModule } from '@alfresco/adf-core';
import { provideAdfEnterpriseAdfHxContentServices } from '@alfresco/adf-hx-content-services';

@NgModule({
    imports: [
        CommonModule,
        CoreModule,
        [...]
    ],
    providers: [provideAdfEnterpriseAdfHxContentServices()]
})
export class AppModule {}
```

That's it!

The `provideAdfEnterpriseAdfHxContentServices` module adds all the providers needed to develop with the lib.
If you like to have a more granular configuration, you can import and provide subsets of the lib:

```ts
import { NgModule } from '@angular/core';
import { ADF_HX_CONTENT_SERVICES_API_PROVIDERS } from '@alfresco/adf-hx-content-services/api';
import { DOCUMENT_PROVIDERS, USER_RESOLVER_PROVIDERS } from '@alfresco/adf-hx-content-services/services';
import { ADF_HX_CONTENT_SERVICES_UI_TRANSLATIONS_PROVIDER, CONTEXT_MENU_ACTIONS_PROVIDERS } from '@alfresco/adf-hx-content-services/ui';

export function provideAdfEnterpriseAdfHxContentServices(): EnvironmentProviders {
    return makeEnvironmentProviders([
        provideTranslations('adf-enterprise-adf-hx-content-services-ui', 'assets/adf-enterprise-adf-hx-content-services-ui'),
        provideTranslations('adf-enterprise-adf-hx-content-services-services', 'assets/adf-enterprise-adf-hx-content-services-services'),
        ...ADF_HX_CONTENT_SERVICES_API_PROVIDERS,
        ...CONTEXT_MENU_ACTIONS_PROVIDERS,
        ...USER_RESOLVER_PROVIDERS,
        ...DOCUMENT_PROVIDERS,
    ]);
}
```

**ADF_HX_CONTENT_SERVICES_API_PROVIDERS** is a collection of Api providers.
Available providers:
- documentApiProvider
- downloadApiProvider
- uploadApiProvider
- userApiProvider
- groupApiProvider
- modelApiProvider
- queryApiProvider
- copyApiProvider
- moveApiProvider
- renditionsApiProvider

**DOCUMENT_PROVIDERS** is a collection of providers to work with Documents.

**CONTEXT_MENU_ACTIONS_PROVIDERS** setup the providers required to use the context action menu

**USER_RESOLVER_PROVIDERS** setup the providers required to use the `UserResolver` pipe

**ADF_HX_CONTENT_SERVICES_UI_TRANSLATIONS_PROVIDER** provides translations to the lib components
