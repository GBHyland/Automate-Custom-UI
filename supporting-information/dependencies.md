## Dependencies in an ADF Application

The _package.json_ defines the external libraries that your ADF application depends on to run. It pulls together:
- Angular framework packages for the app structure, UI, routing, and forms
- ADF / Alfresco packages for content services, process services, extensions, and Alfresco API integration
- Hyland design and UI packages for branding, icons, tokens, and custom UI components
- State management libraries like NgRx for managing app-wide data and behavior
- Auth, GraphQL, and API tools for secure backend communication
- Specialized feature libraries for BPMN/DMN modeling, rich text editing, PDF viewing, Monaco editor, dates, utilities, and translations
